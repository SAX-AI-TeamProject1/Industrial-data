# 스마트 안전장비 도입 효과 — 비율검정(Two-proportion test) 분석

> 프로젝트: K-NAVI (수신호 예측 및 장애물 대응 시뮬레이션 환경 구축)
> 근거자료: 류정·박인선(2025), Crisisonomy 21(6) / News 1(2024)
> 목적: "스마트 안전장비 도입 현장의 재해율이 전국 평균보다 낮다"는 서술을 정식 통계 검정으로 뒷받침

---

## 1. 원자료

| 구분 | 근로자 수 (n) | 사고자 수 (x) | 재해율 |
|---|---|---|---|
| 전국 중소규모 건설현장 (2023년 말 기준) | 576,224명 | 2,656명 (사망 171 + 부상 2,485) | 0.461% |
| 스마트 안전장비 지원 현장 123개소 (2021~2023) | 4,481명 | 16명 (사망 1 + 부상 15) | 0.357% |

- 재해율 정의: 재해율(%) = (재해자 수 ÷ 근로자 수) × 100
- 전국 근로자 수는 논문이 인용한 기사의 원자료에서 확인된 576,224명을 사용 (원문 본문의 "약 570만 명"은 표기 오류로, 재해율 0.461%와 정합하지 않음)

---

## 2. 왜 재해율은 "비율(proportion)" 데이터인가

재해율은 연속형 측정값(반응시간, 정확도 %)이 아니라 **"특정 사건(재해)이 발생했는지 여부"를 전체 모집단(근로자 수)에 대해 집계한 비율**이에요. 이런 데이터는 평균 차이를 검정하는 t-test가 아니라, **두 집단의 비율(발생률) 차이를 검정하는 비율검정(two-proportion test)**을 씁니다.

---

## 3. 가설

| 구분 | 내용 |
|---|---|
| H0 (귀무가설) | 전국 평균 재해율(p1)과 스마트 안전장비 도입현장 재해율(p2)에 차이가 없다 (p1 = p2) |
| H1 (대립가설) | 스마트 안전장비 도입현장의 재해율이 전국 평균보다 낮다 (p1 > p2, 단측검정) |
| 유의수준(α) | 0.05 |

---

## 4. 분석 방법 1 — 2표본 비율 Z-검정 (Two-proportion Z-test)

### 4-1. 개념

두 집단의 표본비율(p1, p2) 차이가, 표본 크기를 고려했을 때 우연이라 보기 어려울 만큼 큰지를 정규분포 근사로 검정하는 방법. 표본이 충분히 크고(각 집단 x, n-x 모두 5 이상), 사건이 서로 독립적일 때 사용.

### 4-2. 표본비율 계산

```
p1 = x1 / n1 = 2,656 / 576,224 = 0.004609  (0.4609%)
p2 = x2 / n2 = 16 / 4,481     = 0.003571  (0.3571%)
```

### 4-3. 합동비율(pooled proportion)

귀무가설(H0: p1 = p2)이 참이라고 가정하면, 두 집단은 사실 하나의 공통된 비율에서 나온 표본이라고 볼 수 있어요. 이 공통 비율을 두 집단을 합쳐서 추정한 것이 합동비율입니다.

```
p_pool = (x1 + x2) / (n1 + n2)
       = (2,656 + 16) / (576,224 + 4,481)
       = 2,672 / 580,705
       = 0.004601  (0.4601%)
```

### 4-4. 표준오차(SE) 계산

```
SE = sqrt( p_pool × (1 - p_pool) × (1/n1 + 1/n2) )
   = sqrt( 0.004601 × 0.995399 × (1/576,224 + 1/4,481) )
   = sqrt( 0.004601 × 0.995399 × 0.0002249 )
   = 0.001015
```

- `p_pool × (1 - p_pool)`: 이항분포의 분산 공식 (사건이 일어날 확률 × 안 일어날 확률)
- `1/n1 + 1/n2`: 두 독립적인 표본비율 차이의 분산은 각 표본비율 분산의 합이므로, 표본 크기의 역수를 더함

### 4-5. z-통계량

```
z = (p1 - p2) / SE
  = (0.004609 - 0.003571) / 0.001015
  = 0.001039 / 0.001015
  = 1.023
```

z값은 "관측된 두 비율의 차이가, 표준오차 몇 배에 해당하는가"를 나타냄. z가 클수록(보통 ±1.96 이상) 우연이라 보기 어려운 차이.

### 4-6. p-value 계산

표준정규분포에서 z=1.025보다 극단적인 값이 나올 확률을 구함.

```
단측 p-value = P(Z > 1.023) = 1 - Φ(1.023) = 0.1531
```

(Φ는 표준정규분포의 누적분포함수)

### 4-7. 결과 판정

**p = 0.153 > α(0.05) → 귀무가설을 기각할 수 없음 → 통계적으로 유의한 차이라고 말할 수 없음**

---

## 5. 분석 방법 2 — Fisher의 정확검정 (Fisher's Exact Test)

### 5-1. 왜 필요한가

Z-검정은 표본이 크고 사건 수가 충분할 때(정규분포 근사가 성립할 때) 신뢰할 수 있어요. 그런데 스마트장비 도입현장의 사고 건수(x2=16)는 상대적으로 작은 편이라, 정규근사의 오차가 있을 수 있습니다. 이때는 **근사 없이 정확한 확률을 계산하는 Fisher의 정확검정**을 함께 보는 게 안전해요.

### 5-2. 2×2 분할표

| | 사고 발생 | 사고 미발생 | 합계 |
|---|---|---|---|
| 도입현장 | 16 | 4,465 | 4,481 |
| 전국 평균 | 2,656 | 573,568 | 576,224 |

### 5-3. 원리

귀무가설(도입 여부와 사고 발생이 무관) 하에서, 이 분할표(또는 이보다 더 도입현장에 유리한 방향의 분할표)가 나올 정확한 확률을 초기하분포(hypergeometric distribution)로 계산.

### 5-4. 결과

```
오즈비(Odds Ratio) = 0.774
단측 p-value = 0.182
```

오즈비 0.774는 "도입현장의 사고 발생 오즈가 전국 평균의 약 77%" 라는 뜻으로, 방향은 감소 쪽이지만 **역시 p > 0.05로 통계적으로 유의하지 않음**.

---

## 6. 신뢰구간 (95% CI)

### 6-1. 계산식

두 비율 차이(p1 - p2)에 대한 95% 신뢰구간은, 두 표본비율이 서로 독립이라는 전제 하에 각각의 분산을 더한 표준오차(unpooled SE)를 사용.

```
SE_diff = sqrt( p1(1-p1)/n1 + p2(1-p2)/n2 )
        = sqrt( 0.004609×0.995391/576,224 + 0.003571×0.996429/4,481 )
        = sqrt( 0.00000000796 + 0.00000079399 )
        = 0.000896

95% CI = (p1 - p2) ± 1.96 × SE_diff
       = 0.001039 ± 1.96 × 0.000896
       = 0.001039 ± 0.001756
       = [-0.000717, 0.002794]
       = [-0.0717%p, 0.2794%p]
```

### 6-2. 해석

신뢰구간이 **0(%p)을 포함**하고 있어요. 즉 "재해율 차이가 0(차이 없음)"이라는 가능성을 통계적으로 배제할 수 없다는 뜻이며, 앞선 유의성 검정 결과와 일관됩니다.

---

## 6-1. 방법론적 점검 — 두 집단이 서로 겹치는가?

### 문제 제기

2표본 비율검정(Z-검정, Fisher's exact test)은 **비교하는 두 집단이 서로 겹치지 않는 독립적인 집단**이라는 것을 전제로 한다. 그런데 스마트 안전장비 지원현장 123개소는 국가가 관리하는 지원사업 대상으로, **전국 중소규모 건설현장(150,059개소) 통계 안에 이미 포함되어 있는 부분집합**일 가능성이 높다.

### 왜 문제가 되는가

p2 그룹(도입현장)이 p1 그룹(전국) 안에 포함되어 있다면, p1(전국 재해율) 자체가 이미 p2의 낮은 재해율에 의해 하향 조정된(dilute된) 값이다. 즉 온전히 "미도입 현장만의 재해율"이 아니라 "미도입 현장 + 도입현장이 섞인 재해율"이므로, 두 집단을 비교하면 **실제 차이보다 작게 추정되는 방향으로 편향**될 수 있다.

### 보정 방법

전국 통계(x1, n1)에서 도입현장(x2, n2)을 제외하여, 순수한 "미도입군"만 분리한 뒤 다시 비교한다.

```
x1_순수 = x1 - x2 = 2,656 - 16 = 2,640
n1_순수 = n1 - n2 = 576,224 - 4,481 = 571,743
p1_순수 = x1_순수 / n1_순수 = 2,640 / 571,743 = 0.004617 (0.4617%)
```

### 보정 전후 비교

| 항목 | 보정 전 (도입현장 포함 가능성 무시) | 보정 후 (순수 미도입군만) |
|---|---|---|
| 미도입군 재해율 | 0.4609% | 0.4617% |
| 절대 차이 | 0.1039%p | 0.1047%p |
| Z-검정 (단측) | z=1.023, p=0.153 | z=1.031, p=0.151 |
| Fisher's exact test | OR=0.774, p=0.182 | OR=0.772, p=0.180 |

### 해석

보정 전후로 결과가 거의 달라지지 않았다. 이는 도입현장(4,481명)이 전국 전체(576,224명)에서 차지하는 비중이 약 0.78%에 불과해, 전국 평균 계산에 주는 영향이 미미하기 때문이다. 즉 **독립성 위반 가능성을 검토하고 보정을 시도했으나, 결론(통계적으로 유의하지 않음)에는 실질적인 영향이 없음을 확인**했다.

### 코드

```python
x1_pure = x1_all - x2
n1_pure = n1_all - n2
p1_pure = x1_pure / n1_pure
# 이하 z-검정, Fisher's exact test는 4장, 5장과 동일한 절차로 재계산
```

## 8. 해석 및 발표 반영 문구

스마트 안전장비 도입 현장(123개소)의 재해율은 전국 평균 대비 22.56% 낮게 나타났으나(0.357% vs 0.461%), 2표본 비율검정 결과 통계적 유의성은 확인되지 않았다(Fisher's exact test, p = 0.182, 95% CI: [-0.07%p, 0.28%p]).

**해석 포인트**:
- 사고는 발생 자체가 드문 사건(rare event)이라, 현재 표본 규모(도입현장 4,481명, 사고 16건)로는 통계적 검정력이 부족할 수 있음
- 방향성(도입현장이 더 낮음)은 일관되게 관찰되나, 확정적 인과관계 주장은 유보하는 것이 통계적으로 정직한 태도
- 이 결과는 "더 정밀한 인지·소통 보완 기술과 데이터 축적이 필요하다"는 K-NAVI 프로젝트의 필요성으로 자연스럽게 연결됨

## 9. 분석 코드 (Python)

```python
from scipy import stats
import numpy as np

# 원자료
x1, n1 = 2656, 576224   # 전국: 사고자수, 근로자수
x2, n2 = 16, 4481       # 도입현장(123개소): 사고자수, 근로자수

p1, p2 = x1/n1, x2/n2

# 1) 2표본 비율 Z-검정
p_pool = (x1+x2)/(n1+n2)
se_pool = np.sqrt(p_pool*(1-p_pool)*(1/n1+1/n2))
z = (p1-p2)/se_pool
p_value_one_sided = 1 - stats.norm.cdf(z)
print(f"z={z:.3f}, one-sided p={p_value_one_sided:.4f}")

# 2) Fisher's exact test
table = [[x2, n2-x2], [x1, n1-x1]]
odds_ratio, p_fisher = stats.fisher_exact(table, alternative='less')
print(f"OR={odds_ratio:.3f}, p={p_fisher:.4f}")

# 3) 95% 신뢰구간
se_diff = np.sqrt(p1*(1-p1)/n1 + p2*(1-p2)/n2)
diff = p1 - p2
ci = (diff - 1.96*se_diff, diff + 1.96*se_diff)
print(f"95% CI: [{ci[0]*100:.4f}%, {ci[1]*100:.4f}%]")
```

## 11. 결론

-국토안전관리원 스마트 안전장비 지원현장(123개소)의 재해율은 전국 평균 대비 22.56% 낮게 나타났으나, 2표본 비율검정 결과 통계적 유의성은 확인되지 않았다(Fisher's exact test, p=0.180). 

-이는 사고가 드문 사건(rare event)이라는 특성상 현재 표본 규모의 검정력 한계에 기인할 가능성이 크며, 관찰된 감소 방향 자체는 다른 선행 통계(중기부 스마트공장 재해 18.3% 감소 등)와도 일관된다. 

-따라서 재해율 감소 효과를 확정적으로 입증했다고 볼 수는 없으나, 방향성 있는 정황 근거로서 K-NAVI와 같은 정밀 인지·소통 보완 기술의 필요성을 뒷받침한다.
