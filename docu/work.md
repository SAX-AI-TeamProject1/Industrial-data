## 데이터 수집 시도 기록 (대응표본 t-검정 쌍 설계 검토)

대응표본 t-검정에 쓸 "쌍(pair)"을 어떻게 잡을지 여러 방식으로 검토했으나, 아래 사유로 모두 보류/기각됨. (→ 이후 아래 07.27 기록대로 비율검정으로 방법을 전환함)

1. **쌍: 동일 현장** — 같은 현장의 스마트장비 도입 전/후 데이터를 확보하려 했으나 실패하여 기각.
2. **쌍: 같은 기계** — Gazebo로 현장 시뮬레이션을 만들고, 같은 기계에서 수신호 감지·객체 탐지 기능을 껐을 때와 켰을 때의 사고재해율을 비교하는 방안.
   - 현장 재해 시뮬레이션이 전제되어야 하는데 현재 상태로는 불가능하여 보류.
3. **쌍: 수신호를 감지하는 대상 (사람 vs 로봇)** — 데이터 수집이 어려워 직접 제작을 시도. 수신호 영상 데이터를 직접 촬영하고 모듈을 만들어 사람과 로봇의 수신호 감지 여부를 비교하려 함. 그러나:
   - 실제 현장의 수신호 감지 부담(신체적·청각적·시각적)과 모듈에서의 감지 부담(인지적)의 성격이 달라 비교의 설득력이 부족.
   - 중장비 작업자의 부주의로 인한 사고 자료 수집이 어려움.
   - → 기각.
