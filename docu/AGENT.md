# AGENT.md

Claude Code 등 코딩 에이전트가 이 저장소에서 작업할 때 따라야 할 안내 문서.

## 프로젝트 개요

산업 데이터를 비교·분석해 **가설을 통계적으로 검증**하는 정형데이터 분석 프로젝트다.

**핵심 가설과 목표:** 스마트장비·로봇 도입이 산업재해를 줄이는가를 검증한다. 이를 위해 스마트장비 도입 **전(前) / 후(後)** 데이터를 각각 수집·비교해 도입의 기대효과를 **정형데이터 분석**으로 분석하고 시각화한다. 구체적인 통계 분석 기법(대응표본 t-검정 등)은 아직 확정하지 않았으며, 데이터가 갖춰진 뒤 적합한 방법을 채택한다.

**현재 상태:** 스마트장비 도입 **전** 데이터 수집까지만 완료된 단계다. 도입 **후** 데이터는 아직 없으며, 따라서 전/후 비교 분석은 아직 수행 전이다. 지금 `asset/`에 있는 CSV(로봇밀도, 대업종별 사고재해자/사망자, 재해정도)와 `src/plane/`의 시각화 스크립트들은 이 "도입 전" 기준 데이터를 탐색적으로 정리·시각화한 결과물이다. `src/origin/산업현황.py`는 아직 비어있는 신규 스크립트(용도 미정). 상세 설계는 `docu/design.md`(현재 비어있음), **진행 상황·작업 이력은 `docu/work.md`** 참고 (작업 완료 시 work.md에 날짜와 함께 기록할 것).

## 아키텍처

가설 검증(도입 전/후 비교) 관점에서, 데이터는 아래 흐름을 따르도록 설계되어 있다. **비교 분석 단계는 아직 구현되지 않았고, 사용할 통계 기법도 미정이다.**

```
원본 CSV (asset/, 스마트장비 도입 "전" 기준 통계 — 고용노동부·IFR)
   ↓
전처리 (2행 헤더 정리, 천단위 콤마 제거, 합계행/열 제외, 업종명 정규화)
   ↓
[구현 완료] 탐색적 집계·시각화 (src/plane/) — 막대그래프/히트맵
   ↓
[미구현] 도입 "후" 데이터 수집 + 동일 전처리
   ↓
[미구현] 도입 전/후 비교 분석 (통계 기법 미정 — 대응표본 t-검정 등 후보)
   ↓
[미구현] 분석 결과 시각화
```

### 모듈 구성

- `asset/` — 원본 CSV 11개, 스마트장비 도입 **전** 기준 데이터(로봇밀도 1, 대업종별 사고재해자 2023~2025 3, 대업종별 사고사망자 2023~2025 3, 대업종별 재해정도 2022~2025 4). 수정 없이 그대로 커밋됨. 도입 **후** 데이터는 아직 없음.
- `src/plane/visualize.py`, `src/plane/visualizetwo.py` — 도입 전 데이터를 탐색적으로 정리·시각화하는 스크립트(핵심 히트맵 4종 + 확장 분석 5종). 통계 검정 로직은 포함하지 않음.
- `src/origin/산업현황.py` — 현재 비어있는 파일. 
- `visualizations/` — 생성된 PNG(커밋됨, 탐색적 분석 결과). 추후 도입 전/후 비교 분석 결과 시각화도 이 폴더에 추가될 예정.
- `docu/` — `work.md`(날짜·작성자별 작업 일지), `design.md`(설계 노트용, 현재 비어있음 — 분석 방법·가설 등 설계를 정리하기 좋은 위치).

## 주요 제약 사항
(수정)
- CSV 원본은 `asset/` 폴더에서만 읽는다. 경로는 `pathlib.Path`로 다루고 하드코딩된 절대경로를 넣지 않는다.
- **"합계" 행/열**은 다른 행·열의 총합이라 그대로 두면 집계·히트맵 색상 스케일이 왜곡된다 — 분석 전 반드시 제외.
- **"요양재해자" 열**(재해정도 CSV)은 사망자를 포함한 나머지 재해정도 열들의 합계이므로 마찬가지로 별도 처리 필요.
- **"기타의사업"** 행은 명시된 9개 대업종에 속하지 않는 나머지를 모두 묶은 잔여 범주라 항상 값이 크게 나온다 — 업종별 비교에서는 보통 제외.
- 대업종명에 공백이 섞여 있는 경우가 있다(예: `"광  업"`, `"농  업"`) — 매칭 전 정규화 필요. 스크립트마다 처리 방식이 다르니 새로 작성할 때는 일관되게 맞출 것.
- 로봇밀도는 2018·2021·2023·2024년만 공개 수치가 존재한다. 결측 연도를 임의로 보간·추정하지 않는다.
- 한글 폰트 설정이 없으면 matplotlib 그래프의 한글이 깨진다 (Windows: Malgun Gothic, macOS: AppleGothic, Linux: NanumGothic).
- 이 저장소의 문서와 주석은 한국어로 작성한다.
